SVN 방식

서버에만 이력이 있음

  • · commit = 서버에 바로 기록
  • · 서버가 멈추면 아무도 작업 기록 못 함

  • · push / pull로 원격과 주고받음
  • · 누구의 복사본으로도 전체 복구 가능

commit은 바뀐 부분만이 아니라 그 순간 전체 상태를 기록합니다.

# A: Publish → PR → merge
# B: Publish → PR → This branch has conflicts 확인

#    → 남길 쪽 선택 → 저장 → + → Commit → Sync Changes

Claude Code는 프로젝트의 CLAUDE.md를 자동으로 읽습니다

## Git 규칙
- main 브랜치에 직접 commit · push 하지 않는다
- 작업 전 main을 최신으로 받고 새 브랜치에서 시작한다
- 브랜치 이름: feat/내용, fix/내용
- 커밋 메시지: "feat: 한국어 설명" 형식
- PR 본문에 관련 Issue(Closes #번호)와
  확인 방법을 적는다
- 충돌이 나면 임의로 해결하지 말고
  양쪽 내용을 설명한 뒤 멈춘다

만드는 방법

Claude Code에 요청:

"CLAUDE.md에 'Git 규칙' 절을 추가해 줘.
내용은 …"

이 변경도 브랜치 → PR → merge로
