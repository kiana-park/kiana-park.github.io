VS Code 열고 터미널 열기

이 가이드는 VS Code 하나로 진행합니다. 아래 명령은 모두 VS Code 안의 터미널에 붙여 넣습니다.

  1. VS Code를 엽니다. 없다면 code.visualstudio.com에서 받아 설치합니다.
  2. 위쪽 메뉴 Terminal → New Terminal(한국어 메뉴는 터미널 → 새 터미널)을 누릅니다. 단축키는 Ctrl + `(숫자 1 왼쪽 키)입니다.
  3. 화면 아래쪽에 터미널이 열립니다. 이 페이지의 복사 버튼으로 명령을 복사해 터미널에 붙여 넣고( + V) Enter를 누릅니다.

여러 줄을 한 번에 붙여 넣을 때 확인 창이 뜨면 Paste(붙여넣기)를 누르세요. 위에서부터 한 줄씩 차례로 실행됩니다.

1

Git · Node.js 확인

VS Code 터미널에 붙여 넣어 세 줄 모두 버전 번호가 나오는지 봅니다. node -v가 v22.12 이상이면 다음 단계로 넘어가세요.

VS Code 터미널
git --version
node -v
npm -v

“찾을 수 없다”거나 버전이 낮게 나온 것만 설치합니다.

Git

git --version을 입력했을 때 설치 창이 뜨면 설치를 누르고 끝날 때까지 기다립니다(5–10분).

Git

git-scm.com에서 Windows 설치 파일을 받아 기본 옵션 그대로 Next를 눌러 설치합니다.

Node.js 22 이상

nodejs.org에서 LTS 버전 설치 프로그램(.pkg.msi)을 받아 기본 옵션으로 설치합니다.

이메일 · 팀 키

회원가입할 이메일 주소, 그리고 강사에게 받은 팀 링크 또는 OpenRouter 키.

새로 설치했다면 VS Code를 완전히 종료(⌘ + Q창 닫기)했다가 다시 열어야 터미널이 git·node를 찾습니다.

2

GitHub에서 내려받기 git clone

내 사용자 폴더(~)로 가서 레포를 복제합니다.

VS Code 터미널
cd ~
git clone https://github.com/pkiin/vibe-teacher.git

끝나면 /Users/내이름/vibe-teacherC:\Users\내이름\vibe-teacher 폴더가 생깁니다.

VS Code로 이 폴더 열기

  1. 메뉴 File → Open Folder…(파일 → 폴더 열기)를 누릅니다.
  2. 창이 뜨면 ⌘ + Shift + H로 사용자 폴더로 가서C:\Users\내이름으로 가서 vibe-teacher를 고르고 열기를 누릅니다.
  3. “이 폴더의 작성자를 신뢰합니까?”가 뜨면 Yes, I trust the authors(예, 작성자를 신뢰합니다)를 누릅니다.
  4. 왼쪽 탐색기에 README.md, package.json 등이 보이면 성공입니다. Ctrl + `로 터미널을 다시 엽니다.

이제 터미널이 자동으로 vibe-teacher 폴더에서 열립니다. 이후 명령은 모두 이 폴더를 연 VS Code의 터미널에서 실행합니다. 다음에 다시 할 때도 File → Open Recent(최근 항목 열기)로 이 폴더를 열면 됩니다.

GitHub 페이지의 Code → Download ZIP으로 받아도 실행은 되지만, 나중에 git pull로 새 버전을 받을 수 없으니 clone을 권합니다.

.env 파일 만들기

.env는 이 앱의 설정 파일입니다. 아래 내용이 그대로 .env가 됩니다. 로그인 정보 두 줄은 모두 같고, OpenRouter 키만 팀마다 다릅니다.

팀 링크로 들어왔다면 자동으로 채워져 있습니다. 키는 이 페이지 밖으로 전송되거나 저장되지 않습니다.
.env


  
VS Code에서 .env 파일 만들기

  
    
    
  1. 위 .env 상자의 복사를 누릅니다.
    2. 
    
  2. VS Code 왼쪽 탐색기에서 파일 목록 아래 빈 곳을 오른쪽 클릭 → New File…(새 파일)을 누릅니다.
    3. 
    
  3. 이름에 .env를 입력하고 Enter. 열린 빈 파일에 붙여 넣고( + V) 저장합니다( + S).
    4. 
  

  
파일 이름은 점으로 시작하는 .env 네 글자 그대로입니다. .env.example은 고치지 않습니다. 탐색기에서 .env가 흐리게 보이는 것은 GitHub에 올라가지 않는 파일이라는 표시라 정상입니다. 터미널에서 chmod 600 .env를 실행하면 이 파일을 나만 읽을 수 있게 됩니다(선택).


  
각 값의 의미

  

    
이름값설명

    
      
SUPABASE_URL 모두 같음https://flcpkhtrrktrcoiakspo.supabase.co회원가입·로그인과 학습 기록을 저장하는 서버 주소

      
SUPABASE_PUBLISHABLE_KEY 모두 같음sb_publishable_MyQ9Z8WEpn_KdxBoQJxEyA_KckkJenM그 서버에 접속하는 공개 키. 화면에 노출돼도 되는 키입니다

      
OPENROUTER_API_KEY 팀마다 다름팀 링크 또는 카톡세션 분석·레포 위키를 작성하는 AI 키. 쓴 만큼 비용이 나가는 키입니다

      
나머지 VIBE_TEACHER_…그대로내 노트북(local)의 127.0.0.1:3318에서 실행한다는 뜻

    
  


  
팀 키는 팀 안에서만 쓰세요. 단톡방·GitHub·화면 공유·스크린샷에 키가 보이지 않게 해 주세요. .env는 .gitignore에 들어 있어서 커밋해도 GitHub에 올라가지 않습니다.

  
키를 지금 넣지 않아도 됩니다. OPENROUTER_API_KEY=를 비워 두면 로그인한 뒤 시작 화면이나 소스 설정 → 설명을 작성할 AI에서 넣을 수 있습니다. .env에 값이 있으면 그 값이 우선합니다.

Node.js 없이 쓰는 Windows 묶음 선택

  
매번 VS Code 없이 start.bat 더블클릭으로 실행하고 싶을 때, 또는 Node.js를 설치하지 않은 팀원 노트북에 나눠 줄 때 씁니다. 5단계까지 잘 됐다면 건너뛰어도 됩니다. 묶음에는 아래 .env.release가 필요합니다.


  
① .env.release 만들기

  
.env.release

  
4단계와 같은 방법으로 탐색기 빈 곳을 오른쪽 클릭 → New File… → 이름 .env.release → 붙여 넣고 저장합니다. 이 두 줄 외에 다른 값(OpenRouter 키 등)을 넣으면 묶음을 만들지 않습니다.


  
② 묶음 만들기

  
VS Code 터미널
npm run package
explorer release

  
Node.js 공식 배포본을 내려받으므로 인터넷이 필요합니다. 끝나면 release 폴더에 vibe-teacher-0.1.0-windows-x64.zip(약 35MB)이 생기고, 두 번째 줄이 그 폴더를 파일 탐색기로 엽니다.


  
③ 실행하기

  
    
    
  1. zip을 오른쪽 클릭 → 압축 풀기. zip 안에서 바로 실행하면 동작하지 않습니다.
    2. 
    
  2. 풀린 vibe-teacher 폴더의 start.bat을 더블클릭합니다. 보안 경고가 나오면 추가 정보 → 실행.
    3. 
    
  3. 브라우저가 열리면 로그인하고, 시작 화면의 OpenRouter 키 칸에 팀 키를 붙여 넣고 키 저장을 누릅니다. 묶음에는 키가 들어 있지 않습니다.
    4. 
  

  
검은 창을 닫으면 앱이 종료됩니다. zip에는 키가 없지만 로그인 서버 정보가 들어 있으니 팀 안에서만 직접 전달하세요. 만드는 중 오류가 나면 5단계의 npm start 방식으로 쓰면 됩니다.

문제 해결

  
git·node·npm을 찾을 수 없다고 나와요
설치한 뒤 VS Code를 완전히 종료했다가 다시 여세요. 열려 있던 터미널은 설치 전 상태를 기억합니다. 그래도 안 되면 1단계의 설치를 다시 확인합니다.

  
Could not read package.json 오류가 나요
터미널이 vibe-teacher 폴더가 아닌 곳에서 열려 있습니다. File → Open Folder…로 vibe-teacher 폴더를 열고 터미널을 새로 연 뒤 다시 실행하세요.

  
“이 시스템에서 스크립트를 실행할 수 없으므로 … npm.ps1”
Windows 보안 설정 때문입니다. VS Code 터미널에서 아래를 한 번 실행하고 Y를 누른 뒤, 원래 명령을 다시 실행하세요.
VS Code 터미널
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

  
npm install이 npm error로 끝나요
node -v가 v22.12 이상인지 확인하세요. 학교·회사 네트워크라면 다른 와이파이에서 다시 시도해 보세요. 그래도 안 되면 마지막 20줄 정도를 캡처해 강사에게 보내 주세요.

  
“3318 포트를 다른 프로그램이 쓰고 있습니다”
먼저 다른 터미널에서 이미 npm start를 실행 중인지 확인하세요. 아니라면 .env의 VIBE_TEACHER_PORT=3318을 3328로 바꾸고 다시 실행한 뒤 http://127.0.0.1:3328로 접속합니다.
포트를 바꾸면 이메일 인증 링크가 새 주소로 돌아오지 못할 수 있으니 강사에게 바꾼 포트를 알려 주세요.

  
인증 메일이 오지 않아요
스팸함을 확인하고, 로그인 화면의 인증 메일이 안 왔어요 → 인증 메일 다시 받기를 눌러 보세요. 그래도 없으면 가입한 이메일을 강사에게 알려 주세요.

  
AI 분석 버튼이 동작하지 않아요 · 승인 대기라고 나와요
AI 생성은 강사 승인 후 쓸 수 있습니다. 승인을 받았다면 승인 상태 확인을 누르거나 다시 로그인하세요. 승인됐는데도 안 되면 .env의 OPENROUTER_API_KEY에 키가 맞게 들어갔는지 확인합니다.

  
대화 기록이 보이지 않아요
이 노트북의 지금 계정으로 Claude Code·Codex·Copilot을 쓴 기록만 보입니다. Claude Code 기록은 ~/.claude/projectsC:\Users\내이름\.claude\projects에 있습니다. 다른 컴퓨터나 서버에서 작업한 기록은 보이지 않습니다.

  
다른 계정으로 처음 로그인해 버렸어요
앱을 끄고(Ctrl + C) ~/.vibe-teacher/local-ownerC:\Users\내이름\.vibe-teacher\local-owner 파일을 지운 뒤, 다시 실행해 본인 계정으로 로그인하세요.

  
키를 바꾸거나 잘못 넣었어요
VS Code에서 .env를 열어 OPENROUTER_API_KEY= 줄을 고치고 저장한 뒤 앱을 다시 실행합니다(Ctrl + C → npm start).
