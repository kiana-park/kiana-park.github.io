준비 ① · 필수

구글 드라이브 — 계정 만들기

계정 만들기 → accounts.google.com/signup

드라이브 → drive.google.com

1

구글 계정이 없다면 먼저 위 '계정 만들기'에서 가입합니다.

2

드라이브 접속 drive.google.com 에 구글 계정으로 로그인.

3

확인 좌측 '+ 새로 만들기'로 폴더가 생기는지 확인.

TIP 이미 Gmail을 쓰고 있다면, 그 계정을 그대로 사용하면 됩니다.

구글 클래스룸 — 수업 참여

classroom.google.com

1

접속 · 로그인 classroom.google.com 에 구글 계정으로 로그인.

2

수업 참여 우측 상단 '+' → '수업 참여' 클릭.

3

코드 입력 강사가 안내한 수업 코드를 입력하고 참여.

준비 ① · 필수

openrouter — 가입하기

openrouter.ai

1

접속 openrouter.ai 에서 '가입(Sign up)' 클릭.

2

가입 이메일 또는 구글 계정으로 가입 → 이메일 인증.

3

기억 Get API Key 하고 이 키를 노션, 구글문서, 메모장 등에 저장.

준비 ② · 필수

준비 ③ · 필수

Claude — 가입하기

claude.ai

1

접속 claude.ai 에서 '가입(Sign up)' 클릭.

2

가입 이메일 또는 구글 계정으로 가입 → 이메일 인증.

3

기억 이 계정을 뒤의 'Claude Code 확장' 로그인에 씁니다.

TIP Claude Code 확장 사용에는 유료 구독(Pro 등) 또는 Console 계정이 필요할 수 있어요.

준비 ④ · 필수

GitHub — 가입하기

github.com/signup

1

접속 github.com/signup 으로 이동.

2

정보 입력 이메일 · 비밀번호 · 사용자명(username) 입력.

3

인증 이메일로 온 인증 코드를 입력하면 완료.

TIP 사용자명은 나중에 프로젝트 주소에 쓰이니, 부르기 쉬운 걸로 정하세요.

준비 ⑤ · 필수

VS Code — 다운로드 · 설치

code.visualstudio.com/download

1

접속 code.visualstudio.com/download 으로 이동.

2

내 OS 선택 Windows 또는 Mac 버튼을 눌러 다운로드.

3

설치 · 실행 설치 파일을 실행해 설치 → VS Code를 엽니다.

TIP Mac은 다운로드한 앱을 '응용 프로그램(Applications)' 폴더로 옮기면 됩니다.

준비 ⑥ · 필수

Claude Code — VS Code 확장 설치

확장 설치 안내(공식 문서) → code.claude.com/docs/en/vs-code

1

확장 열기 VS Code에서 Windows Ctrl+Shift+X / Mac Cmd+Shift+X.

2

검색 · 설치 "Claude Code" 검색 → 게시자가 Anthropic인 것 설치.

3

열기 · 로그인 파일 하나를 연 뒤 Spark(✱) 아이콘 클릭 → Claude 계정 로그인.

주의 비슷한 이름의 비공식 확장이 있습니다 — 반드시 게시자가 'Anthropic'인 것을 설치하세요. (확장에 CLI가 내장돼 터미널 설치는 필요 없습니다.)
