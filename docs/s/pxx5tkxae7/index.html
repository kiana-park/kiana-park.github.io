테이블 (표)

표 한 장 = 한 종류의 데이터. 우리는 bookings(예약) 표를 만듭니다.

행 (row)

컬럼 (column)

세로 한 칸 = 항목. 이름·연락처·인원처럼 무엇을 받을지 정합니다.

Connect 버튼은 어디에?

Supabase 프로젝트 화면 위쪽 가운데의 초록색 Connect 버튼입니다. (예전 방식대로 Project Settings → API Keys로 들어가도 같은 값이 나옵니다.)

1️⃣ Connect → Server 탭 — 네 줄을 한 번에

모달 위쪽에서 Server (Build APIs) 탭을 고릅니다. 2. Set environment variables 항목의 Copy all 버튼을 누르면 네 줄이 통째로 복사됩니다.

2️⃣ Connect → Direct connection string 탭 — 한 줄 더

같은 모달에서 Direct Connection string 탭으로 이동하고, Connection Method는 Direct connection, Type은 URI로 둡니다.

완성된 .env — 이 다섯 줄

.env — 이렇게 생겼습니다값은 각자 것
# ── Supabase 대시보드 > Connect > Server 에서 Copy all ──
SUPABASE_URL=https://wsmcsqnqrclbrqqrbtfm.supabase.co
SUPABASE_PUBLISHABLE_KEY=sb_publishable_xxxxxxxxxxxxxxxx
SUPABASE_SECRET_KEY=sb_secret_xxxxxxxxxxxxxxxx
SUPABASE_JWKS_URL=https://wsmcsqnqrclbrqqrbtfm.supabase.co/auth/v1/.well-known/jwks.json

# ── Supabase 대시보드 > Connect > Direct connection string > URI ──
# 마이그레이션 / 직접 접속이 필요할 때만
SUPABASE_DB_URL=postgresql://postgres:내DB비밀번호@db.wsmcsqnqrclbrqqrbtfm.supabase.co:5432/postgres

다섯 개가 각각 무슨 값인가

변수 이름어디서무엇인가 · 왜 필요한가
SUPABASE_URLConnect → Server 내 데이터베이스의 주소입니다. “어느 집으로 갈지”. 공개돼도 괜찮습니다 — 주소를 안다고 문이 열리지는 않으니까요.
SUPABASE_PUBLISHABLE_KEYConnect → Server 공개용 열쇠(옛 anon key). 손님 화면에서 쓰는 열쇠입니다. 이 열쇠로 할 수 있는 일은 표에 걸어둔 정책(RLS)이 허용한 것뿐입니다.
SUPABASE_SECRET_KEYConnect → Server 마스터 열쇠(옛 service_role key). 정책을 전부 무시합니다. 서버 코드에서만 씁니다. 오늘 만들 관리자 목록이 이걸 씁니다.
SUPABASE_JWKS_URLConnect → Server ‘로그인한 이 사람이 진짜 맞는지’ 서버가 확인할 때 쓰는 공개키 주소입니다. 5강·로그인 붙일 때 필요합니다. 지금 당장 안 써도 같이 넣어두면 나중에 다시 찾으러 갈 일이 없습니다. 공개돼도 안전한 값입니다.
SUPABASE_DB_URLConnect → Direct connection string 데이터베이스에 직접 들어가는 주소(비밀번호 포함). 평소 앱 코드는 이걸 쓰지 않습니다. Claude Code에게 SQL을 직접 실행시키거나, 표 구조를 한꺼번에 바꾸거나(마이그레이션), 백업을 뜰 때 씁니다. 절대 비밀입니다.
SUPABASE_DB_URL — 반드시 손봐야 할 곳

복사한 주소에는 postgres:[YOUR-PASSWORD]@db… 처럼 자리표시자가 들어 있습니다. 대괄호까지 통째로 지우고 프로젝트 만들 때 저장해둔 DB 비밀번호를 넣으세요.

비밀번호에 @ # ? / : 같은 특수문자가 있으면 주소가 깨집니다. 그럴 땐 아래 프롬프트로 변환하거나, Supabase에서 Reset database password로 특수문자 없는 비밀번호를 새로 만드는 편이 빠릅니다.

Direct connection이 안 될 때 (IPv6)

Direct connection은 IPv6를 기본으로 씁니다. 일부 네트워크(특히 회사·학교 와이파이)는 IPv6를 못 써서 연결이 실패합니다. 그럴 땐 같은 모달에서 Transaction pooler 또는 Session pooler 주소를 대신 복사해 쓰면 됩니다.
오늘 실습에서는 이 값을 안 써도 진도가 나갑니다 — 안 되면 일단 비워두고 넘어가세요.

⚠️ SQL Editor 에서 already exists / does not exist 오류
