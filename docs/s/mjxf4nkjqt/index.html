실습 ① 요청문

Claude Code에 그대로 붙여 넣습니다

my-intro에 다듬기 기록을 저장하는 기능을 추가해 줘.
DB는 .env의 DATABASE_URL(내 개인 DB)을 쓰고, 테이블 이름은 intro_logs로 해 줘.
칸: id, 원래 문장, 면접용 · SNS용 · 발표용 결과, 만든 시각.
다듬기가 성공하면 저장하고, 화면 아래에 최근 기록 5개를 보여 줘.
DB 접속은 서버(app/api)에서만 하고, 값은 따로 넘기는 방식으로 쿼리해 줘.
.env.sample에 DATABASE_URL= 이름을 추가하고, README.md도 업데이트해 줘.
DB 주소 · 비밀번호는 코드 · 로그 · 화면에 쓰지 마.
확인되면 커밋하고 푸시해 줘. 계획을 먼저 보여 줘.

    Claude Code에 맡긴다면

    직접 명령 대신 이 요청문을 써도 됩니다

    실습서버의 내 개인 DB를 Supabase로 옮기려고 해.
개인 DB 주소는 .env의 DATABASE_URL이고, Supabase Session pooler 주소는
내가 터미널에 NEW_DB_URL로 넣어 둘게.
1) 지금 DB의 테이블 목록과 테이블별 행 수를 먼저 보여 줘.
2) pg_dump --no-owner --no-privileges 로 내보내고 psql로 넣어 줘.
3) Supabase 쪽 행 수를 세어 1)과 표로 비교해 줘.
주소 · 비밀번호는 화면에 출력하지 말고, 백업 파일은 git에 올라가지 않게 해 줘.
